# 配置与源码索引

产品入口为 `WorkspaceApp → WorkspaceSession → VerdFrame → FrameCanvas → CellRuntime`。会话按文件持有 FrameFileV2 并组装成单一 CellStore，标准与第三方模式共用 Frame API。嵌入与详情通过 frameId 挂载同一份数据，`frame-reference` 引用壳按目标文件渲染，派生布局只存在于运行时。子图归属在文件外层的 `organization`，由 `frame-organization.ts` 派生导航索引；单文件编辑走 `edit-file`，不会用整仓替换删掉其他文件。引用实例的出现路径在 `canvas-session.ts`。

面向 AI 的数据生成（全字段表、元素目录、约束与示例）见 [ai-canvas-data-spec.md](./ai-canvas-data-spec.md)。

## 画布与工作区

| 能力           | 源码                                                                                                                                                        | 修改入口                                                                           |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 模型与快照     | `packages/engine/core/src/cell/types.ts`                                                                                                                    | FrameSnapshot、CellStore、Node/Edge/Group/Frame 类型                               |
| 原子事务与历史 | `packages/engine/core/src/cell/runtime.ts`、`index.ts`                                                                                                      | 候选操作、关系归一化、最终校验、实际变更历史                                       |
| 索引与校验     | `packages/engine/core/src/cell/index.ts`、`validation.ts`                                                                                                   | 父级、成员、入出边；重复 id、层级环、跨 Frame 关系                                 |
| 坐标与 Frame   | `packages/engine/core/src/cell/frame.ts`                                                                                                                    | 根不画外壳、嵌套缩小居中、内容坐标与聚焦路径                                       |
| React 运行时   | `packages/react/board/src/frame-canvas.tsx`                                                                                                                 | 标准 value/onChange、宿主 adapter/onIntent、控制器、选择和交互                     |
| 产品工具与属性 | `packages/product/ui/src/verd-frame.tsx`                                                                                                                    | 绘图、外观、主题、缩放适配、导航和导入导出                                         |
| 工作区会话     | `packages/product/app/src/session/workspace-session.ts`                                                                                                     | 命令候选校验、统一历史、保存队列、外部同步与冲突                                   |
| 宿主存储       | `packages/product/app/src/host/`                                                                                                                            | fs/IndexedDB 条件提交、回收区、事务日志、订阅                                      |
| 文件分区与引用 | `packages/product/app/src/frames/frame-files.ts`                                                                                                            | FrameFileV2 分区/组装、引用图、复制闭包、导入导出                                  |
| 旧数据迁移     | `packages/product/app/src/migration/`                                                                                                                       | 备份、稳定 id 映射、共享文档拆分、未挂载文档、加载错误                             |
| 工作区外壳     | `packages/product/app/src/workspace-app.tsx`、`packages/product/ui/src/{file-tree,file-tree-menu,workspace-settings,settings-page-shell,chart-library}.tsx` | 侧栏文件树与行菜单、标签栏、图表库、两个设置页；样式令牌在 `styles/workspace.scss` |

主题保存在 FrameCell.view，使用 replace_cell 事务更新；视口只由当前画布会话在内存中维护。历史、选择、布局缓存和 DOM 不写入快照。全屏演示的聚焦目标、步骤、相机与激光笔只在会话内存，不写入快照、历史或保存状态。旧 `FrameCell.presentation` 字段被忽略，不迁移或主动重写。旧平铺 StorageAdapter 仅作迁移输入；`verd-cells` 信封仅是迁移输入。

全屏演示与目标解析在 `packages/product/ui/src/presentation/presentation-mode.tsx`、`presentation-targets.ts`，样式在同目录 `presentation.scss`。独立只读覆盖层中的 FrameCanvas 负责命中和相机控制，复用编辑画布相同的注册与渲染扩展。脑图从总览开始，按根主题顺序依次遍历各根的一级分支，根主题本身不作为单独步骤；架构图按层序提供步骤。`0` 总览、`L` 激光笔、`Esc` 退出；退出恢复编辑视口。Web/Desktop 共用这一入口，旧稿件生成器、播放协议、观众页面及 Electron 观众 IPC/preload 已删除。画布相机入口是 `FrameCanvasController` 的 `fitBounds`、`fitCells` 和 `getContentBounds`；`inputMode="present"` 的 `onPresentTap` 只报告当前 Frame 对象，嵌入内容映射为外壳，不改变选择。渲染扩展的 `FramePresentation` 外观 Hook 继续保留。

## 迁移边界与验收

旧 React 画布、领域 Canvas、SceneGraphic、投影宿主与样式入口已删除。core、引擎和产品中的旧元素 API、插件和文档 reducer 也已删除。旧 JSON 定义和前向转换仅保留于 packages/product/app/src/migration/legacy，未作为公开 API 导出。运行时迁移已落地，体验回归仍待完成，清单见 [体验回归验收](./体验回归验收.md)。

验收覆盖类型检查、单测、实际自动保存、全部产品 E2E、Web/Desktop 最新构建和严格隔离 consumer。构建退出成功仍需解决类型声明诊断。具体要求见 [架构与验收状态](../architecture/ARCHITECTURE.md)、[画布模式](../packages/board/canvas-modes.md) 和 [开发指南](../development/README.md)。

## 产品设置与操作偏好

Web/Desktop 的左上角「更多」菜单统一提供打开、文件 / 文本导入、文件 / 图像及场景文本导出、清空和设置入口。撤销、重做和保存状态仍直接展示。

设置是应用内全屏页面，返回后保留原画布实例、视口、选择、工具和撤销历史。语言沿用 `I18nProvider` 与 `localStorage.language`；触控板缩放灵敏度和拖动画布速度保存在 `localStorage['verdboard.interaction-settings']`，即时应用于本设备所有画布。默认 `1×`，范围 `0.25×–3×`，步长 `0.05×`；「恢复默认手感」只恢复两项速度。偏好模块负责校验与持久化，画布通过 `interactionSettings` 接收倍率。

入口：产品 UI 的 `frame-app-menu.tsx`、`frame-settings-page.tsx` 与 `interaction-preferences.ts`；画布行为位于 React board 的 `frame-canvas.tsx`。这些设置不属于文档主题，也不参与文件导入导出。

## 对齐、排列与 Group

Core 的 `cell/arrangement.ts` 统一排列块、六向对齐、分布和自动排列，`group.ts` 提供递归边界/锁定/焦点解析；React 的 `frame-alignment.ts` 计算参考线吸附，`FrameCanvasController.executeSelectionCommand` 统一提交。产品的 `frame-arrangement.tsx` 供右侧与右键菜单共用。领域旧坐标由 Workflow/Architecture 引擎的物化 helper 在加载/导入边界转换；规则与兼容说明见 [排列与组合](../packages/board/arrangement.md)。

## Sidebar、名称与 Port 显示

`verd-frame.tsx` 与 `styles/frame.scss` 实现画布外 300px Sidebar、互斥属性上下文和形状选择；`frame-actions-popover.tsx` 保存运行时选择目标，捕获阶段关闭外部点击。`core/cell/name.ts` 在事务插入/正文首次改变时处理独立 `NodeCell.name`；`react/board/frame-canvas.tsx` 在正文会话结束时提交空节点名称。`core/geometry/edge-display.ts` 只裁切显示路径，`react/board/frame-edge-stroke.tsx` 局部订阅两端可见性，`frame-camera-store.tsx` 提供节点悬停订阅。名称与新交互规则见 [React API](../packages/react/README.md#sidebar节点名称与连接交互)。

## 内容尺寸与 Mind 最大宽度

应用默认宽度保存在 `localStorage['verdboard.mind-settings']`，默认 240；`mind-preferences.ts`、`frame-settings-page.tsx` 管理偏好，`frame-mind-properties.tsx` 管理根节点 `maxNodeWidth` 覆盖。引擎 `mind/cell-metrics.ts` 与布局统一处理宽度上限、媒体及高度；React text 的 `measure-text.ts` 复用预览 serializer 做离屏富文本度量。React board 的 `frame-fit-content.ts` 处理选中普通节点的尺寸适配，产品排列面板与右键菜单共用控制器命令。

## 右侧属性面板

`packages/product/ui/src/frame-property-panel.tsx` 提供 300px 固定标题 / 内部滚动外壳与可访问折叠分组；折叠状态仅保留当前画布会话。`frame-property-number.tsx` 使用 `value/onCommit` 保存数字草稿，Enter / 失焦提交、Esc 还原，空值与越界输入不会写入模型；选择身份或权限改变时丢弃草稿。`verd-frame.tsx` 保留权限检查、最新节点读取、事务与领域控制器命令，按能力组织几何、外观、文本、专属设置、排列图层与操作。

外观、文本、Mind、排列分别在 `frame-selection-appearance.tsx`、`frame-selection-text.tsx`、`frame-mind-properties.tsx`、`frame-arrangement.tsx`；控件与面板样式集中在 `styles/frame-properties.scss`。Mind 属性接收与布局一致的工作区有效默认宽度；全局和工作区设置仍使用即时应用的 `frame-mind-width-input.tsx`。产品 API 与存储格式不变。

数字行为和单步历史验证见 `frame-property-number.spec.tsx`、`frame-view-state.spec.tsx`；Web 属性面板的中英文、1440×900 / 1280×720、各领域与内部滚动验证见 `tests/web-e2e/src/property-panel.spec.ts`；Desktop 数字单步历史、锁定与重启持久化见 `tests/desktop-e2e/src/property-panel.spec.ts`。
