# Mind 特性说明（技术）

脑图使用原生 CellStore，公开接入与验收状态见 [Cell/Frame 画布模式](./canvas-modes.md)。旧 MindElement、MindTransforms 和领域 Canvas 已删除，旧 JSON 的转换仅位于应用私有迁移目录。

## 数据与选中

中心主题为 `mind-root`，子主题为 `mind-child`，树关系通过 `mind-branch` 的源/目标 ID 表达。普通节点不保存 parent 或 children。概要通过独立 `mind-summary-edge` 保存首尾兄弟 ID。

嵌入状态选择 Frame 外壳表示整个容器，选择主题表示单个节点。详情视图通过 frameId 挂载同一数据，容器缩放不重写内容坐标。中心主题不能折叠或改父级，最后一个中心主题不能删除；删除其他中心主题会级联删除其树并可完整撤销。

## 布局、编辑与历史

`cell-utils.ts` 将分支树交给 layouts 包，`cell-metrics.ts` 为主题、图片、表情和笔记计算区域。`cell-drag.ts` 根据指针落点及当前布局几何解释兄弟重排或改父级，维护分支顺序、左右分配及概要范围。拖动预览不进入历史，完成后提交一笔事务。

主题标题（包括概要）默认左对齐；笔记默认左对齐且顶部对齐。已有文档或段落明确设置的居中、右对齐仍保留。浏览、原位编辑及属性面板共用有效默认值，打开或关闭编辑器不会将默认值写入快照或新增历史；新空笔记明确使用左对齐。编辑工具栏读取当前段落对齐，多选属性按全部文字块计算共同值或混合值。

主题生长侧有隐藏的改父级热区，向外延伸 40 CSS px，沿边两端各扩 12 CSS px，并随缩放和嵌入比例换算；标准双向中心主题左右均有热区。拖动主题面对目标的边中点进入热区即可捕获，重叠热区按距目标端口最近、再按 Frame 内顺序选择。仍支持鼠标拖入主题正文。命中当前父级继续同级排序；自身、后代、隐藏、锁定和跨 Frame 目标不可捕获，同 Frame 可跨树调整。

候选父级以强调色描边，35% 透明度的 ghost 展示整条可见分支的预计落位、内部连接与概要，以及临时父子连接线。预览通过独立候选快照计算，不改变真实数据、内容适配、历史、保存或导出；临时连接线从当前显示父节点出发。离开热区或取消手势立即清理，松手重新解析并提交一笔事务；折叠父级只在提交后展开。提交复用候选布局，正常内容适配可能整体缩放或平移。

白板内拖动嵌入脑图的中心主题，只平移该根所属的可见树和概要，外层 Frame 及同框其它树保持不动。位置保存在 `MindRootData.embeddedOffset?: Point`，单位为内容坐标，旧数据缺省为 `[0, 0]`；详情使用原始树布局，不应用嵌入偏移。基础布局负责内容适配，显示布局负责节点、连线、命中、选区及导出，松手后不会再次居中抵消拖动。

偏移范围由整棵可见树的视觉边界限制，所有节点始终留在内容区；内容铺满的方向无法继续移动。增删节点、折叠和外框缩放后重新限制有效偏移，拖动期间不自动缩放。偏移参与单次事务、撤销重做及保存；编辑文字、锁定、缩放或旋转不会把显示偏移重复写入节点坐标。拖动预览绑定目标和手势，取消或开始另一手势会清理旧预览。

贝塞尔分支保留父主题侧边的共同起点。正向相对端口的控制点按增长方向间距的一半计算，使密集同级分支保持顺序，避免远处子主题拉长手柄后回弯相交；缩进等非相对端口继续保留原有切线。可见路径、透明命中线和图像导出共用同一条曲线。

新增子主题和同级主题继承相应父级/兄弟样式，保留原有中心主题不向子主题复制样式的规则。字体 marks、字号、颜色和对齐继承，文本身份与内容重新生成，链接不复制；图片、笔记和布局覆盖不随新主题复制。大字号和换行参与主题尺寸计算。Tab/Enter 创建主题后，在事务接受并回写数据后选中新主题。

笔记使用 BoardTextDocument，与主题富文本分离，支持独立折叠。属性面板的笔记编辑将每次内容变化提交为 Cell 事务；导航和 Desktop 关闭经过同一保存队列。图片上传、尺寸、表情、手动宽度、分支样式和主题形状由原生属性面板修改。

概要的布局和括号渲染共用首尾兄弟 ID。选中概要主题或括号后可以拖动手柄调整范围；删除覆盖节点会收缩范围，无剩余覆盖节点时移除概要。撤销恢复概要和关联数据，图像导出保留括号并移除编辑手柄。

## Mind 配色与文件级配置

`FrameView.mind.colorScheme` 保存当前 Mind 文件的配色方案（默认、缤纷、柔和、复古、暗色、星空）。缺省表示继承文件画布主题（`view.theme.themeColorMode`）；选择"继承画布"删除覆盖字段而不是复制当前颜色；未知值在读取时回退继承，不回写文件。同一文件内所有树共享方案，嵌入视图与详情视图读取源文件配置；保存、复制和原生导入导出原样保留该字段，不迁移旧文档。

色板定义与解析在 Mind 引擎 `cell-theme.ts`：标题、笔记默认文字色、中心主题填充/描边、分支与概要色按 显式标记 > 分支继承 > 当前方案 > 画布主题 > 默认色板 的顺序逐属性解析。笔记颜色经 `mindNoteColor` 解析后显式传给渲染组件；Frame 配置变化即使子节点引用不变也会刷新标题、笔记、连线和概要（外观缓存携带描边色比较），但不触发文本重新测量。局部设色的标题不再把首个片段颜色提升为整题默认色。

## 笔记文本格式

属性面板对带笔记的主题显示"笔记文本"分组：粗体、斜体、下划线、删除线、字号（默认 13）、颜色与"跟随主题"、左/中/右对齐，作用于整篇 `data.note`。控件状态由 `boardTextFormatState` 按域默认值解析：混合值显示"混合值"/三态，非预设字号显示实际值，空笔记禁用需要文字叶节点的控件并提示"输入笔记内容后可调整文字样式"（对齐仍可用）。"跟随主题"只清除 `textStyle` 的颜色属性，保留其他 marks。`formatBoardText` 应用补丁时保留链接、段落结构和无关标记；重复设置相同值不产生历史。

画布静态预览、画布内编辑器与右侧编辑器共用 13px + 方案笔记色；右侧编辑器显式声明笔记默认样式，不继承侧栏字号。显式字号标记参与笔记测量（无 DOM 估算路径同样读取），大字号笔记不重叠。

## 整树布局

`cell-tree.ts` 提供整树事务 helper：`mindTreeRootId`/`mindTreeNodeIds` 定位所属树（含概要），`setMindTreeLayout` 一次返回更新根布局、清除全部普通主题与概要局部覆盖（含折叠后代）、恢复左右自动分配所需的 `CellOperation[]`；UI 不自行遍历树。`setMindTreeRightNodeCount` 校验 `0～一级主题数` 的有限整数，`undefined` 恢复自动分配。属性面板对根主题与普通主题都显示所属树布局并注明"应用于整棵树"；存在局部覆盖时提供"统一整树布局"。九种布局入口：常用区域左右对分/向右/向下，"更多布局"包含其余六种。

## 节点内容适配与最大宽度

Mind 根节点、子节点和概要按内容派生宽高；默认最大外框宽度 240 画布单位，超过后换行，高度不设上限。设置页可管理本设备全局默认（整数 80–2000）；根节点属性可选择跟随默认或设置本图覆盖值。覆盖值保存为 `MindRootData.maxNodeWidth`，参与保存、撤销及文件导入导出；应用默认不写入图文件。嵌入、详情和图像导出使用相同配置。

Mind 尺寸拖拽关闭；旧 `manualWidth`、固定几何尺寸字段仍可加载，但不参与显示尺寸。图片等比缩放，表情换行，展开笔记计入节点高度。React 使用共享富文本 schema 和样式进行不受相机缩放影响的离屏度量；引擎在无 DOM 时保留估算。尺寸和布局缓存不写入快照。

普通文本形状、流程节点、架构模块可在排列面板和右键菜单执行「根据内容调整大小」。仅处理选中对象（组合展开当前 Frame 内成员），以操作前宽度为上限，短内容收窄、长内容换行增高，保持位置、旋转和富文本格式。空内容、锁定对象、图片、表格、泳道、Frame、架构层、线条及 Mind 跳过。批量变化作为单次事务提交，支持一次撤销；重复操作无变化时不产生历史记录。
