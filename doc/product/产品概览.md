# 青编（VerdBoard）产品概览

本文档从**产品视角**描述青编（VerdBoard）的定位、能力与使用形态，面向产品/设计评审、新成员 onboarding，以及与架构、开发文档互补阅读。实现细节见 [架构文档](../architecture/ARCHITECTURE.md) 与 [包文档索引](../packages/README.md)。

**最后更新**: 2026-10-14

---

## 1. 产品定位

青编（VerdBoard）是一款**一体化数字白板**，在同一画布上整合：

- **思维导图** — 结构化发散与层级整理
- **流程图** — 流程、关系与图形符号表达
- **自由绘画** — 手绘感线条、箭头等草图能力
- **工作流** — 独占编辑器，以及常规白板上的特殊组件（任务 / 判断）
- **富文本** — 标题、列表、表格等版式内容（基于 TipTap）

底层由 **Board 引擎（`@sue/board-*` 分包）** 驱动，采用 **SVG 渲染** 与 **插件化** 扩展方式，在交互性能与可扩展性之间做平衡。

## 2. 目标用户与典型场景

| 用户类型            | 典型诉求                         | 青编提供的价值                                                 |
| ------------------- | -------------------------------- | -------------------------------------------------------------- |
| 个人知识工作者      | 一屏内完成脑图 + 备注 + 简单图示 | 单画布多模态，减少工具切换                                     |
| 产品与项目协作      | 梳理需求、流程、里程碑           | 流程图与思维导图并存，结构清晰                                 |

## 3. 核心能力（产品语言）

### 3.1 思维导图

- **主题文字与拖拽**：标题默认左对齐，笔记默认左、上对齐，保留显式格式。拖入主题生长方向的隐藏热区可调整父子关系；高亮候选父节点和半透明分支预览提示落位，松手统一提交，支持撤销与保存恢复。

- 多种布局与主题样式，支持节点级自定义。
- **整图选中**：Mind 提供覆盖整棵树的背景包裹区域语义；可单独选中「整张导图」以调整默认样式，也可像普通节点一样选中**根节点**编辑主题样式与内容，二者在选中框与右侧属性面板上区分明确。
- **框选**：框住整棵 Mind 时表现为选中整体；仅框住部分分支时为多选节点。
- **节点笔记 / 布局 / 图片**：在独占脑图工作区编辑；常规白板上的脑图特殊组件只保留改名、展开收起与整图拖动。
- **独占工作区**：整张画布只做脑图。完整产品中从白板上的脑图组件进入；改完写回同一棵白板树。
- 常规白板上的脑图是有边界的组件（子节点不能离开这棵树独立存在）。双击整图或点「打开」进入独占编辑器。
- 技术落点见 [Mind 特性说明（技术）](../packages/board/mind-features.md) 与 [画布模式](../packages/board/canvas-modes.md)。

### 3.2 流程图

- 几何图形与流程图符号库，用于表达控制流与结构关系

### 3.3 自由绘画与图形

- 手绘风格线条、箭头、表格等绘图工具，适合快速标注与草图
- 左侧「图表」菜单统一创建思维导图、流程图和架构图；「连线」菜单提供箭头、直线与曲线，直线和曲线默认没有箭头，可在属性中修改端点。
- 独立折线属于图形节点，入口位于「形状」面板；连线可吸附并绑定节点。图表与连线菜单支持方向键选择、Enter 确认、Esc 和点击外部关闭。

### 3.4 工作区子图

- 只有思维导图、流程图和架构图进入子图管理。子图只能属于一张普通画布，不能属于另一张专业图，层级只有两层。
- 「提升为独立图表」只改变工作区归属，不改变图表类型。一份子图一份内容、一个所有者，可以有任意多处合法引用；删、移、加引用都不会自动改所有者。
- 普通画布引用普通画布是只读预览，预览内部也不能编辑；外壳仍可移动、缩放和删除。双击或「打开原画布」进入原文件。
- 侧边栏里，普通画布和独立图表留在原来的目录。已归属的子图出现在所属画布下面，默认收起。待整理的子图只在图表库里出现。
- 图表库是主内容页，不是文件标签。列表按名称排序，可按名称、类型和归属交叉筛选。整理已有图表只预览还没有 organization 的专业图，确认后整批一次撤销。
- 引用已有图表只插入一个引用壳，不复制内容，也不改变对方的归属。

侧边栏每行的 `⋯` 或右键打开操作菜单，包括重命名、副本、导出和移入回收区；子图还能更改所属画布、提升为独立图表、标记待整理。目录里可以新建画布、文档和文件夹。回收区默认收起。

### 3.5 富文本

- 基于 TipTap 的段落与行内编辑，支持常见文档结构（标题、列表、表格等）。
- 思维导图节点的主题行与附属笔记在数据与编辑链路上分离，笔记为段落级能力；详见 [Mind 特性说明（技术）](../packages/board/mind-features.md) 第二节。

### 3.6 工作流

- **独占工作区**：整张画布只做节点图，复用画布引擎，canonical 数据是版本化文档，不写入白板 `BoardElement[]`。
- 从节点面板拖入或点击添加任务 / 判断节点，支持连线、删除、复制与属性改名。
- 每份文档可在 **DAG**（默认，禁止回路）与 **传统流程**（允许多节点回路，仍禁止自环）之间切换。
- **常规白板**：可以插入 workflow 特殊组件。它是整块组件：可移动、可点选内部节点改名，画面与独占详情共用同一场景；连线、端口、Palette 只在独占编辑器中使用。双击组件进入同一 `documentId` 的独占编辑；标题栏返回白板。
- Web 与 Desktop 共用 `@sue/verd-board-app` 的持久化适配器与文档仓库；完整产品不提供顶层 Mind / Workflow 直切入口。
- 模式约定见 [画布模式](../packages/board/canvas-modes.md)。

### 3.7 主题与外观

- 内置主题与可扩展的主题系统，保证画布内各类元素视觉一致
- 网格与间距、容器比例预设随 Frame 保存；组合与多选统一调整外观和文字格式
- 右侧与右键菜单提供六向对齐、等距分布和显式自动排列；拖动显示可吸附的智能参考线，Alt 临时关闭。
- Group 支持嵌套、逐层进入/退出、逐层解组和独立锁定，整体排列保持内部相对位置。白板、流程节点和架构模块支持，Mind 内部保持树布局。详见 [对齐、自动排列与组合](../packages/board/arrangement.md)。
- 清空先确认，保留必须存在的领域锚点并可一次撤销；白板对象可移动到另一 Frame，关联箭头和坐标同步处理

### 3.8 性能与扩展

- SVG 管线下的流畅交互
- Cell Util、注册器和渲染扩展便于新增节点类型、交互与导入导出能力

### 3.9 设置与操作偏好

左上角「更多」菜单收纳打开、导入、导出、清空与设置；撤销、重做和保存状态保持直接可用。全屏设置页提供语言、触控板缩放灵敏度与拖动画布速度，操作偏好即时应用于本设备所有画布，刷新或重启后保留。返回设置前的画布时保留视口、选择与撤销历史。

侧栏底部「工作区设置」打开独立的全屏页，只管理这个工作区的名称和思维导图默认宽度（优先于全局值）。全局偏好仍在画布「更多 → 设置」，工作区设置页里也有入口。

### 3.10 演示

白板、思维导图、流程图和架构图可在独立只读覆盖层中全屏演示当前画布内容，复用编辑画布相同的渲染扩展，从总览开始，点击对象聚焦；思维导图从总览开始，按根主题顺序依次展示各根的一级分支，根主题不单独占一步；架构图按层提供上一步／下一步。`0` 返回总览，`L` 切换激光笔，`Esc` 退出并恢复编辑视口。所有演示状态仅在会话内存中，不写入文档或撤销历史。

本轮移除幻灯片生成和编排、标题与备注、临时笔迹、计时、自动播放、演讲者视图和独立观众窗口，不提供双屏同步、远程观众、PPT 导出或跨文件串联。旧文件中的 `presentation` 数据忽略，不新增迁移或主动重写。

## 5. 设计原则（摘要）

- **一体化画布**：白板与领域详情共用 FrameCanvas；详情通过 frameId 编辑同一份数据。
- **可扩展**：核心与业务功能通过 Util、注册器和渲染扩展划分，便于迭代与二次开发。
- **文档可读**：文档与代码结构面向团队可读、可导航。

### 属性与节点交互

右侧属性栏为画布外 300px 的独立 Sidebar，通高、可滚动和收起；800px 窗口保持右侧布局。属性按位置、外观、文本和排列分组，单选/多选/空选择分别呈现元素、共有属性和画布设置。开关不改变视口和撤销历史。工具与底部控制位于画布内，视图适配使用实际画布尺寸。

对象名称与画布正文独立，名称为单行纯文本，正文保留富文本。自动名称在已有正文节点插入或空节点首次完整编辑结束时生成，后续正文修改不改名，显式空名称有效。Port 平时隐藏，悬停、选择或连接时显示；连线在可见 Port 圆周外结束，导出恢复到节点边界。形状菜单打开时进入选择态，选定形状后才创建；连线菜单提供双向箭头。右键菜单固定打开时的目标，外部左击立即关闭并继续原点击或拖动。

Mind 主题按内容自动适配，长内容在最大宽度处换行，高度不限。默认最大宽度 240，可在设置页修改，也可在各图根节点配置中覆盖。普通文本形状、流程节点与架构模块可对选中对象执行「根据内容调整大小」，保持位置并支持一次撤销。规则见 [节点内容适配与最大宽度](../packages/board/mind-features.md#节点内容适配与最大宽度)。
