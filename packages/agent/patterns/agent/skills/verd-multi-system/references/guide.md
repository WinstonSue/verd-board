## 单一主入口与分层

大型项目应选择一份文档或一张通用画布作为统一阅读入口，默认推荐文档，避免同时维护两套总览。

以文档为主入口时，由文档组织说明与导航；画布如需分层，总览画布只嵌入图表 Frame，无需再嵌入文档。

以通用画布为主入口时，由画布统一组织图表与文档；配套文档聚焦具体内容，无需再汇总整套画布。正文仍可按需引用局部图表，避免双重汇总和反复嵌套，降低阅读与维护复杂度。

## 编写与验证

实例化参数：title 为根文件标题；工具自动生成独立身份。模板实例化会重新映射整个引用闭包。

编辑示例：先 inspect 获得身份与正文块，再使用 document.splice、node.upsert 或对应关系操作，plan 后 validate 与 preview。

结构规则：以 verd rules 和 describe 返回的已安装版本为准。视觉布局需要复核预览。

## 示例边界与人工重试
